# Sessions

- **Thursday:** a reading. See [`readings.md`](readings.md).
- **Friday:** a technical session. Each Friday with shared work gets a folder named `YYYY-MM-DD-topic`.

Inside a Friday folder, each person adds their own subfolder (`yourname-model`) with a README based on [`../templates/show-and-tell.md`](../templates/show-and-tell.md).

Anything that grows beyond one session can move to [`../projects/`](../projects/).
