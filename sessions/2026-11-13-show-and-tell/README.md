# Show and tell, Friday 2026-11-13

Bring one small model you found or built. It can be a homeostat, a perceptron, a thermostat, a Braitenberg vehicle, or anything else. It can be AI-written. It can be unfinished.

The emphasis is on describing it: what it's doing, and whether it does what it's supposed to. A little discussion of the code is welcome but not required.

## Related reading

Franchi, S. (2013). Homeostats for the 21st century? Simulating Ashby simulating the brain. *Constructivist Foundations* 9(1): 93–101. [ResearchGate](https://www.researchgate.net/publication/277596924_Homeostats_for_the_21st_Century_Simulating_Ashby_Simulating_the_Brain)

The reading group discussed its opening sections on 2026-10-01 ([session notes](https://blog.jopro.org/p/simulating-objects-simulating-concepts)). Franchi separates simulating an object, where a model is judged by how closely it matches the real thing, from simulating a concept, where the model is a tool for thinking. It's a useful question to ask of any model brought to this session: which of the two is it doing?

## How to add yours

1. Make a folder here named `yourname-model`.
2. Copy [`../../templates/show-and-tell.md`](../../templates/show-and-tell.md) into it as `README.md` and fill it in.
3. Add whatever files go with it.
