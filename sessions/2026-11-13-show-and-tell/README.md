# Show and tell, Friday 2026-11-13

Bring one small model you found or built. It can be a homeostat, a perceptron, a thermostat, a Braitenberg vehicle, or anything else. It can be AI-written. It can be unfinished.

The emphasis is on describing it: what it's doing, and whether it does what it's supposed to. A little discussion of the code is welcome but not required.

## How to add yours

1. Make a folder here named `yourname-model`.
2. Copy [`../../templates/show-and-tell.md`](../../templates/show-and-tell.md) into it as `README.md` and fill it in.
3. Add whatever files go with it.
