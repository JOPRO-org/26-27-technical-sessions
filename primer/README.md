# Primer: simulating minds, agents, and the things around them

People keep asking a version of the same question: if I want to simulate something in cognition, mental health, active inference, cybernetics, or multi-agent behavior, what can I reasonably do, and where do I start?

This primer is our attempt at an answer. It is built from what we actually try. Each model brought to a session can add a short entry here on what it captures, what it can't, and what we learned.

It is early. Most of what's here is questions.

- [`questions.md`](questions.md): the questions the primer is trying to answer
- [`entries/`](entries/): one short page per model tried
