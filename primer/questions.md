# Questions the primer is trying to answer

These are open. Answers get added as entries accumulate.

## What can be simulated?
- Which phenomena have been usefully simulated, and which resist it?
- When is a simulation a model of a mechanism, and when is it a model of a concept?
- What does a simple model (a homeostat, a perceptron) actually show, and what doesn't it show?

## At what level?
- When should you model one agent, many agents, or a population?
- How much body, environment, and development does a model need before it says anything interesting?
- What changes when agents can change their own structure?

## Known limits
- What do simulations of minds and mental health typically leave out, and does it matter?
- How do you tell an emergent result from one you built in?
- When does a model flatten differences between individuals that matter?

## Where to start
- What are good first models for someone new to this?
- Which tools suit which questions (Python, NetLogo, agent-based modeling libraries)?
- What should every model state about itself?
