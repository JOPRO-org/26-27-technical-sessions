# Primer entries

One short page per model tried, named after the model (for example `homeostat.md`). Each entry links to the session folder where the model lives and answers three things:

1. What concept or phenomenon this model captures.
2. What it can't capture.
3. What we learned from trying it, including what surprised us.

Entries are distilled from the show and tell READMEs. They don't replace them.
